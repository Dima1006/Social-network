# Social Network API

A REST API for a simple social network, built with **FastAPI** and **SQLAlchemy**. Users can sign up, log in, publish posts and vote on other people's posts. It is a learning project that follows a typical production layout: routers, schemas, JWT authentication and database migrations.

## Features

- Sign up and log in with e-mail and password (passwords are hashed with bcrypt)
- JWT bearer authentication
- Create, read, update and delete your own posts
- List posts with pagination (`limit`, `skip`) and search by title (`search`)
- Vote and un-vote on posts; every post comes back with its vote count
- Database migrations with Alembic
- Interactive API docs (Swagger UI) generated by FastAPI

## Tech stack

Python, FastAPI, SQLAlchemy, SQLite, Alembic, Pydantic, python-jose (JWT), passlib + bcrypt, uvicorn.

## Getting started

```bash
git clone https://github.com/Dima1006/Social-network.git
cd Social-network
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Create a `.env` file in the project root. The settings class requires all of these variables, even though the app currently stores data in a local SQLite file (`database.db`):

```env
DATABASE_HOSTNAME=localhost
DATABASE_PORT=5432
DATABASE_PASSWORD=password
DATABASE_NAME=social
DATABASE_USERNAME=postgres
SECRET_KEY=put-a-long-random-string-here
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_TIME=60
```

`SECRET_KEY` signs the tokens: use a long random value. `ACCESS_TOKEN_EXPIRE_TIME` is the token lifetime in minutes.

Create the tables and start the server:

```bash
alembic upgrade head
uvicorn app.main:app --reload
```

Open http://127.0.0.1:8000/docs to try the API in the browser.

## API overview

| Method | Endpoint | Auth | Description |
| --- | --- | --- | --- |
| POST | `/users/` | no | Create a user (`email`, `password`) |
| GET | `/users/` | no | List users |
| GET | `/users/{user_id}` | no | Get one user |
| POST | `/login` | no | Log in with form fields `username` (the e-mail) and `password`; returns a bearer token |
| GET | `/posts/` | yes | List posts with vote counts. Query: `limit` (default 10), `skip`, `search` |
| POST | `/posts/` | yes | Create a post |
| GET | `/posts/{post_id}` | yes | Get one post with its vote count |
| PUT | `/posts/{post_id}` | yes | Update your post |
| DELETE | `/posts/{post_id}` | yes | Delete your post |
| POST | `/vote/` | yes | Vote (`dir: 1`) or remove your vote (`dir: 0`) on a post (`post_id`) |

Authenticated requests need the header `Authorization: Bearer <access_token>`. In Swagger UI, press **Authorize** and log in with your e-mail and password.

### Example

```bash
# 1. sign up
curl -X POST http://127.0.0.1:8000/users/ \
  -H "Content-Type: application/json" \
  -d '{"email": "me@example.com", "password": "secret123"}'

# 2. log in and copy the access_token from the response
curl -X POST http://127.0.0.1:8000/login \
  -d "username=me@example.com&password=secret123"

# 3. create a post
curl -X POST http://127.0.0.1:8000/posts/ \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{"title": "Hello", "content": "My first post"}'
```

## Project structure

```
app/
  main.py        FastAPI app and router registration
  config.py      settings loaded from .env
  database.py    SQLAlchemy engine and session
  models.py      User, Post and Vote tables
  schemas.py     Pydantic request and response models
  oauth2.py      JWT creation and verification
  utils.py       password hashing helpers
  routers/       auth, user, post, vote endpoints
alembic/         database migrations
```
